== Description ==

MT Senda is a minimalist editorial WordPress block theme developed with accessibility, performance, privacy, and sustainability in mind.

The project aims to provide a lightweight foundation for blogs, personal websites, portfolios, and small organizations.

This theme is currently under development and is not ready for production use.

== Installation ==

1. Download the development version from GitHub.
2. Upload the theme directory to wp-content/themes/.
3. Activate MT Senda from Appearance > Themes.
4. Customize the theme using the WordPress Site Editor.

== Frequently Asked Questions ==

= Is MT Senda a block theme? =

MT Senda is being developed as a native WordPress block theme.

= Does MT Senda require additional plugins? =

The goal is to work without mandatory third-party plugins.

= Is MT Senda accessibility-ready? =

Accessibility is a core development objective. Accessibility testing has not yet been completed.
