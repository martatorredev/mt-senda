# MT Senda

A lightweight WordPress block theme with a minimalist editorial design, developed with accessibility, performance, privacy, and sustainability in mind.

> Status: Early development. Not ready for production use.

## About

MT Senda is a free and open-source WordPress block theme created by Marta Torre.

The project aims to provide a clean, flexible foundation for blogs, personal websites, portfolios, and small organizations.

## Project goals

- Accessibility: follow WCAG 2.2 AA principles where applicable.
- Performance: minimize unnecessary CSS, JavaScript, and external dependencies.
- Sustainability: prioritize efficient resource usage and lightweight pages.
- Privacy: avoid unnecessary third-party requests and tracking.
- Simplicity: use native WordPress blocks and Full Site Editing.
- Internationalization: use English as the source language and support translations.

These are development goals, not claims of completed testing or certification.

## Planned features

- Native WordPress block theme.
- Global styles configured through `theme.json`.
- Responsive layouts.
- Header and footer template parts.
- Blog and page templates.
- A small collection of block patterns.
- Light and dark style variations.

## Development

The theme is currently under development.

The project will be tested using WordPress theme review tools, accessibility checks, and manual browser testing before submission to WordPress.org.
