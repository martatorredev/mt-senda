# MT Senda

A lightweight, open-source WordPress block theme with a minimalist editorial design, built with accessibility, performance, privacy, and sustainability in mind.

> **Status:** Version 1.0.0 submitted to the WordPress.org Theme Directory. Awaiting review and approval.

## About

MT Senda is a free and open-source WordPress block theme created by Marta Torre.

It provides a clean, flexible foundation for blogs, personal websites, portfolios, and small organizations, using native WordPress blocks and Full Site Editing.

## Features

- Native WordPress block theme with Full Site Editing support.
- Global styles configured through `theme.json`.
- Responsive editorial layouts.
- Custom header and footer template parts.
- Templates for posts, pages, archives, search results, and 404 pages.
- Four editorial block patterns.
- Default color palette and two additional style variations: Paper and Forest.
- System fonts without external font dependencies.
- Keyboard navigation and visible focus styles.
- Translation-ready strings.

## Project principles

- **Accessibility:** follow WCAG 2.2 AA principles where applicable, including keyboard accessibility, visible focus indicators, and readable contrast.
- **Performance:** minimize unnecessary CSS, JavaScript, and external dependencies.
- **Sustainability:** prioritize efficient resource usage and lightweight pages.
- **Privacy:** avoid unnecessary third-party requests and tracking.
- **Simplicity:** favor native WordPress functionality over additional dependencies.
- **Internationalization:** use English as the source language and support translations.

These principles guide development and should not be interpreted as claims of accessibility certification or comprehensive compliance testing.

## Compatibility

- WordPress 6.6 or later.
- PHP 7.4 or later.
- Full Site Editing support.

## Testing and review

Version 1.0.0 has undergone automated checks using WordPress Theme Check, along with manual browser, responsive layout, and keyboard navigation testing.

The theme passed the automated checks during submission to the WordPress.org Theme Directory.

**WordPress.org review:** [Ticket #301179](https://themes.trac.wordpress.org/ticket/301179)

Automated checks do not constitute final approval or comprehensive accessibility certification.
